# ❤️ Heart Disease Prediction

## 📌 Overview

This project predicts whether a patient has heart disease using classification models.

## 🚀 What I did

* Data preprocessing using Pipeline
* Handling missing values and scaling
* Model training:

  * Logistic Regression
  * Random Forest
  * XGBoost
* Model comparison using ROC-AUC
* Threshold tuning for better decision-making

## 📊 Final Result

* **Best Model:** Random Forest
* **Accuracy:** ~86%
* **ROC-AUC:** ~0.935

## 🧠 Key Learnings

* Accuracy is not enough in classification
* ROC-AUC is a better metric
* Threshold tuning improves recall
* Feature importance helps interpretation

## 🛠 Tech Stack

* Python
* Pandas, NumPy
* Scikit-learn
* XGBoost
